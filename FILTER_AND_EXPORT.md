## 📋 How to Use

### **Filter Results by Exam:**

1. Go to **Admin Dashboard**
2. Scroll to **Student Results** section
3. Use the **dropdown** at the top left
4. Select an exam (e.g., "Mock batch 65")
5. Results table updates automatically
6. Only shows results for that exam

### **Export Results to CSV:**

1. **Optional:** Filter by specific exam first
2. Click **"Export CSV"** button
3. CSV file downloads automatically
4. Filename includes exam name and date
5. Open in Excel or Google Sheets
