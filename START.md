- Password: `admin123`

### 2. Create Your First Exam

- Fill in exam details
- Add questions with explanations

### 3. Students Take Exam
- Go to Student Interface: http://192.168.68.105:5001
- Select an exam
- Enter name and start

## 🛑 To Stop the Server

Press `Ctrl+C` in the terminal where the server is running.

---

## ⚠️ Troubleshooting

### Can't access from other devices?
1. Make sure other devices are on the same Wi-Fi network
2. Check your Mac's firewall settings
3. Try accessing from a different device

### Port 5001 is in use?
- The server will automatically find another port
- Check the terminal output for the new port number
